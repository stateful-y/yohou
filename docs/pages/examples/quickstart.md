# Quickstart

Get up and running with Yohou in minutes. The [Quickstart notebook](/examples/quickstart/) is a single end-to-end tour: loading data, fitting a baseline forecaster, and generating predictions with minimal setup, then going further into preprocessing pipelines, decomposition, cross-validation search, and interval prediction.

Because it ranges beyond a first forecast, it is also listed among the [Getting Started](getting-started.md) notebooks, which cover each of those steps one at a time.
